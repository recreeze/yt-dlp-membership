📖 Overview Pendahuluan

This guide explains how to prepare a Windows computer for yt-dlp and related tools.

Panduan ini menjelaskan cara mempersiapkan komputer Windows untuk yt-dlp dan tools terkait.

⚠️ Important: Penting: Use yt-dlp only for content you are legally authorized to download. Respect copyright and platform rules. Gunakan yt-dlp hanya untuk konten yang secara hukum memang boleh kamu download. Hormati hak cipta dan aturan platform.

📋 Prerequisites Persyaratan

  • Windows 10 or Windows 11
  • Google Chrome
  • Python 3.x
  • Node.js LTS
  • Deno
  • FFmpeg
1

Prepare Google Chrome Siapkan Google Chrome

  1. Install Google Chrome if it is not already installed. Install Google Chrome jika belum terpasang.
  2. Sign in to the account that has legitimate access to the content you want to use. Login ke akun yang memiliki akses sah ke konten yang ingin digunakan.
  3. Verify that the content can be accessed normally, not a private video. Pastikan konten dapat diakses secara normal, bukan private video.
2

Install Python

  1. Download Python from Download Python dari python.org .
  2. During installation, enable Saat instalasi, aktifkan Add Python to PATH.
  3. Finish the installation. Selesaikan instalasi.

Verify: Verifikasi: 

python --version

Example: Contoh: 

Python 3.x.x
3

Install Node.js

  1. Download Node.js LTS from Download Node.js LTS dari nodejs.org .
  2. Install it using the default options. Install menggunakan opsi default. 
node --version
npm.cmd --version
4

Install Deno

Deno is an alternative JavaScript runtime. It may be useful for some yt-dlp JavaScript-related configurations.

Deno adalah JavaScript runtime alternatif. Deno dapat berguna untuk beberapa konfigurasi yt-dlp yang berkaitan dengan JavaScript. 

irm https://deno.land/install.ps1 | iex

Verify: Verifikasi: 

deno --version
5

Install FFmpeg

winget install Gyan.FFmpeg
⚠️ After installation, completely close PowerShell or CMD and open a new terminal so the updated PATH can be loaded. Setelah instalasi, tutup PowerShell atau CMD sepenuhnya lalu buka terminal baru agar PATH yang diperbarui dapat terbaca. 
ffmpeg -version
6

Install yt-dlp

python -m pip install -U yt-dlp

Verify: Verifikasi: 

python -m yt_dlp --version
7

Install yt-dlp-ejs

python -m pip install -U yt-dlp-ejs

This package provides JavaScript-related support for supported yt-dlp configurations.

Package ini menyediakan dukungan terkait JavaScript untuk konfigurasi yt-dlp yang didukung.

8

Verify Everything Verifikasi Semuanya 

python --version
node --version
npm.cmd --version
deno --version
ffmpeg -version
python -m yt_dlp --version
✓ All available commands should display version information without errors. Semua command yang tersedia seharusnya menampilkan informasi versi tanpa error.
9

Export Cookies Export Cookies

Make sure the account you use has permission to access the content. Do not attempt to bypass membership, DRM, authentication controls, or other access restrictions.

Pastikan akun yang digunakan memang memiliki izin untuk mengakses konten. Jangan mencoba bypass membership, DRM, kontrol autentikasi, atau pembatasan akses lainnya.

🔐 Security: Keamanan: Never publish session tokens, browser cookies, authentication files, or other account credentials. Jangan pernah mempublikasikan session token, cookie browser, file autentikasi, atau kredensial akun lainnya.
  1. Open YouTube in Chrome. Buka YouTube di Chrome.
  2. Make sure you are logged in. Pastikan sudah login
  3. Click the extension icon. Klik ikon ekstensi pada browser.
  4. Export cookies in Netscape format. Eskpor cookies sebagai Netscape format.
  5. Save the file as Simpan file dengan nama 
    cookies.txt
10

Download the Video Download Video nya

Replace VIDEO_URL with the actual URL.

Ganti VIDEO_URL dengan URL yang ingin didownload. 

python -m yt_dlp --sub-langs all --write-subs --cookies "Lokasi Tempat Cookies\cookies.txt" --remote-components ejs:npm -f "bv*+ba/b" --merge-output-format mp4 "VIDEO_URL"

Make sure FFmpeg is available, yt-dlp can combine separate video and audio streams when the download is completed.

Pastikan FFmpeg tersedia, yt-dlp dapat menggabungkan stream video dan audio terpisah apabila selesai mendownload.

⚠️ Warning: Peringatan: One Membership video requires cookies in the currently open tab. If you want to download another video, export the cookies in the other tab. Satu video Membership membutuhkan cookies di tab yang sedang dibuka, jika ingin mendownload video yang lain maka ekspor cookies di tab lainnya.

📁 Download Videos to a Specific Folder Download Video ke Folder Tertentu

By default, downloaded files are saved in the current working directory.

Secara default, file hasil download disimpan di folder tempat command dijalankan.

Create a dedicated folder:

Buat folder khusus:

mkdir MyVideos
cd MyVideos

You can also specify an output template directly:

Kamu juga dapat menentukan lokasi output secara langsung: 

python -m yt_dlp -o "MyVideos/%(title)s.%(ext)s" "VIDEO_URL"

Example structure: Contoh struktur: 

Downloads
└── MyVideos
    ├── video-1.mp4
    ├── video-2.mp4
    └── video-3.mp4

❓ Frequently Asked Questions (FAQ)

Q: ffmpeg is installed but Windows says "ffmpeg is not recognized"?

Close all PowerShell/CMD windows and open a new terminal. This allows Windows to load the updated PATH.

Tutup semua PowerShell/CMD lalu buka terminal baru. Ini memungkinkan Windows membaca PATH yang telah diperbarui.

Q: npm gives an Execution Policy error?

On Windows PowerShell, try the Windows command wrapper:

Di Windows PowerShell, coba gunakan command wrapper Windows: 

npm.cmd --version
Q: yt-dlp is not recognized?

Use the Python module form instead of relying on the yt-dlp executable being present in PATH.

Gunakan format Python module daripada bergantung pada executable yt-dlp yang tersedia di PATH. 

python -m yt_dlp --version
Q: Do I need Deno?

Not necessarily. Different yt-dlp configurations may use different JavaScript runtimes. Node.js is commonly useful, while Deno is an alternative runtime.

Tidak selalu. Konfigurasi yt-dlp yang berbeda dapat menggunakan JavaScript runtime yang berbeda. Node.js umum digunakan, sedangkan Deno merupakan alternatif.

Q: Can I keep the downloaded videos forever?

Downloaded files stay on your computer until you delete them. Make sure you have enough disk space because large playlists can consume many gigabytes.

File yang diunduh akan tetap tersimpan di komputer Anda hingga Anda menghapusnya. Pastikan Anda memiliki ruang disk yang cukup karena playlist yang besar dapat menghabiskan banyak gigabyte.

Q: How much storage do I need?

Storage requirements depend on resolution, codec, bitrate, duration, and the number of videos.

Kebutuhan storage bergantung pada resolusi, codec, bitrate, durasi, dan jumlah video.
